# Palabrón

Sopa de letras 6×6 en castellano para retar a tus amigos, con criaturas que evolucionan.

Web estática: `index.html` + `dic.txt` (diccionario) + iconos y manifiesto para instalarla como app.
Netlify la publica tal cual (sin build), desde la raíz del repositorio.

## Créditos de datos
- `comunes.txt`: lista de palabras frecuentes derivada de [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, datos de OpenSubtitles), licencia CC BY-SA 4.0, filtrada con el diccionario del juego.
